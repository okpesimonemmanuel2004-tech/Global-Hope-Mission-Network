# Global Hope Evangelistic Mission Network — Website

## Overview
This is the official website for **Global Hope Evangelistic Mission Network**.
Built with HTML5, CSS3, and vanilla JavaScript — no frameworks required.

---

## How to Use

1. Download or copy all three files into one folder.
2. Create an `images/` subfolder inside the same folder.
3. Add your real ministry photos using the filenames listed above.
4. Open `index.html` in any web browser to view the site.
5. Upload all files to your web hosting provider to go live.

---

## How to Update Content

### Update Impact Numbers
Open `index.html` and find any element with `data-target`.
Change the number in `data-target` to update the counter.

### Update Contact Information
Search for the placeholder contact details in `index.html`:
- Email: `info@globalhopeemn.org`
- Phone: `+234 800 000 0000`
- WhatsApp: `https://wa.me/2348000000000`
- Location: `Plateau State, Nigeria`

Replace each one with your real ministry contact details.

### Update Social Media Links
Search for `href="#"` near the social media icon buttons and
replace `#` with your actual social media profile URLs.

### Update Gallery Photos
Replace the image files in the `images/` folder with your
real ministry photos. Keep the same filenames or update the
`src` attributes in `index.html` to match your new filenames.

### Connect the Contact Form
The contact form currently simulates a submission.
To connect it to a real email service, open `script.js`
and find the comment block that says **FORM SUBMISSION NOTE**.
Follow the instructions there to connect to EmailJS,
Formspree, or your own server.

### Update Colors
Open `style.css` and find the `:root` section at the top.
Change the color values under **Brand Colors** to adjust
the entire website color scheme at once.
